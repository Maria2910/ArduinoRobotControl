# Управление роботом через Bluetooth

## Описание
Мобильное приложение для управления Arduino-роботом с двумя режимами:
- Управление кнопками
- Управление джойстиком

## Технологии
- MIT App Inventor
- Arduino
- Bluetooth HC-05

## Файлы
- `RobotControl.aia` - проект App Inventor
- `RobotControlSketch.ino` - скетч Arduino
- `RobotControlUI` - внешний вид приложения
- `RobotControlBlocks` - скриншоты кода из mit app inventor
