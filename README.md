# Управление роботом через Bluetooth

## Описание
Мобильное приложение для управления Arduino-роботом с двумя режимами:
- Управление кнопками
- Управление джойстиком

## Технологии
- MIT App Inventor
- Arduino
- Bluetooth HC-05

## Файлы
- `robot-control.aia` - проект App Inventor
- `arduino/robot_sketch.ino` - скетч для робота
